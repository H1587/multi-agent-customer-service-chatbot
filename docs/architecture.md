# Architecture

## Request flow
1. The customer submits a message through the Gradio chat interface.
2. `contextualize_message` uses Gradio history to rewrite short follow-ups as standalone requests when relevant.
3. A router LLM classifies the message as `faq`, `order`, or `recommendation`.
4. LangGraph sends the request to the matching specialist node.
5. The specialist agent uses its assigned tool and returns a response to Gradio.

## Components

### Gradio interface and context
The interface calls `chat_with_customer_service(message, history)`. History is provided by Gradio. Conversations are not persisted to a separate database.

### Router
`route_customer_message` asks the configured Groq model to choose one intent: FAQ, order, or recommendation. Unexpected classifications fall back to FAQ.

### FAQ agent
The FAQ agent calls `search_faq_tool`, which performs similarity search over FAQ documents in a FAISS vector store. Embeddings use `sentence-transformers/all-MiniLM-L6-v2`.

### Order agent
The order agent calls `lookup_order_tool`, which queries the SQLite `orders` table. The sample schema includes an ID, customer name, product, price, and status.

### Recommendation agent
The recommendation agent calls `recommend_products_tool`. Recommendations are generated by deterministic rules based on sample purchase history, not by a trained recommender system.

### LangGraph
The graph has a router node and three specialist nodes (`faq`, `order`, and `recommendation`). Conditional edges select one specialist based on the router's intent, then the specialist node ends the graph.

## Current prototype boundaries
- The database and FAQ data are sample/local data, not a live business backend.
- Tracking numbers and estimated delivery dates are not stored.
- Conversation history is session-provided and is not durable.
- The design handles one specialist route per message; it is not a multi-agent handoff loop.
- Authentication, authorization, production observability, systematic evaluation, and deployment hardening are outside the current prototype.
